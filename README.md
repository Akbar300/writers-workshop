# Writer's Workshop

Calm, game-like writing practice for a Grade 3 and a Grade 5 writer: Sentence Gym, Paragraph Builder,
Fix My Misses, Write a Piece (plan, draft, check, publish; type it or write on paper), Fix This Writing,
and a Grown-ups page with a home rubric and US Letter printables. Built on the Virginia 2024 English SOL.

Static site, no build step: open `index.html`. Progress is saved only in this browser (localStorage).
Tests: `node tools/test.mjs`. See `PLAN.md` for the design.
